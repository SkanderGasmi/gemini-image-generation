# Gemini Image Generation with Vertex AI

A Python project exploring AI-powered image generation using Google's Gemini models and Vertex AI.

## Technologies
- Python
- Google Gen AI SDK
- Google Cloud Vertex AI
- Jupyter Notebook

## Features
- Google Cloud authentication
- Text-to-image generation
- Image configuration and visualization

## Getting Started

```bash
git clone https://github.com/SkanderGasmi/gemini-image-generation.git
cd gemini-image-generation
pip install -r requirements.txt

```

Configure your Google Cloud credentials, then run the notebook
